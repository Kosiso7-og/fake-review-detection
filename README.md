\# Fake Review Detection



A senior seminar project comparing traditional machine learning and transformer-based NLP models for detecting deceptive and AI-generated online reviews.



\## Current Progress



\- Project structure created

\- Python virtual environment created

\- Initial machine-learning dependencies installed

\- First baseline model in progress



\## Planned Models



\- TF-IDF + Logistic Regression

\- TF-IDF + Support Vector Machine

\- Random Forest

\- LSTM

\- Transformer-based model such as DistilBERT
